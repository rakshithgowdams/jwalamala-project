# 10 — ADVANCED CONTENT AND ENGAGEMENT FEATURES

## T — Tags, topics and trending

### T1 Tags and topic hubs
- Tags: many per post; shown as "#tag" chips under the article and on cards (max 2 on cards).
- Tag page `/tag/[slug]`: listing template (02 P-02) + follow button + RSS.
- Topic hub `/topic/[slug]`: a curated page for a big ongoing subject (e.g. "ಶ್ರವಣಬೆಳಗೊಳ ಮಹಾಮಸ್ತಕಾಭಿಷೇಕ", "ಚಾತುರ್ಮಾಸ 2026"). Editor sets: cover image, Kannada intro, pinned stories, key facts box, timeline, linked live blog, linked events, auto-feed by tags. Hub can be marked "active" to appear in the trending bar.
- Admin tag tools: merge, rename, redirect old tag slug, suggested tags (AI, §12), tag usage counts, "hide from trending".
- Tag cloud / "ಜನಪ್ರಿಯ ಟ್ಯಾಗ್‌ಗಳು" block on category and search pages.

### T2 Trending topics bar (second header row)
- Horizontal scrollable row under the category menu, like the reference: flash icon + top hot topic (ember), then items: "ವಿಡಿಯೋ", "ಶಾರ್ಟ್ಸ್", hashtags (#topic), utility links (ಹವಾಮಾನ, ಜೈನ ಪಂಚಾಂಗ, ಜಲಾಶಯ ಮಟ್ಟ), "ವೆಬ್‌ಸ್ಟೋರಿ", place links (#ಹಾಸನ ಸುದ್ದಿ).
- Items come from `trending_items` (editor order) plus optional auto items (top 3 tags by views in last 24h, if enabled).
- Each item: label_kn, link, type (tag/topic/page/category/external), icon, highlight flag, start/end time.
- Live dot on "ಲೈವ್" item when a stream is live.

## C — Content formats

### C1 Listen to article (ಕೇಳಿ) — P1
- Floating round button bottom-left (like the reference) on article pages + inline "ಈ ಸುದ್ದಿ ಕೇಳಿ (3 ನಿಮಿಷ)" button under the title.
- Player bar: play/pause, 10s back/forward, speed (0.75–1.5×), progress, close; keeps playing while scrolling; Media Session API for lock-screen controls.
- Audio generation: Edge Function `generate-article-audio` runs on publish (and on major edit): strip HTML → split text into chunks within the provider limit (≈2,500 chars for Sarvam Bulbul REST) at sentence boundaries → synthesize kn-IN → concatenate → store MP3 in bucket `article-audio` → save `post_audio` row (url, duration, voice, text_hash).
- Regenerate only if text hash changes. Editor can choose voice and pace, or disable audio per post.
- Cost guard: monthly character budget in settings; skip generation when exceeded and alert admin.
- Fallback: if no generated audio, use browser `speechSynthesis` with a kn-IN voice when available; otherwise hide the button.
- Storage exception: this is the ONE allowed media storage (audio), sized small (mono 64 kbps MP3). Get client approval.

### C2 Quick summary (ಸಂಕ್ಷಿಪ್ತ) — P1
- Box at top of article with 3–5 bullet points.
- Draft generated by AI in the editor (§12 AI), always reviewed and saved by an editor; never auto-published.
- Also used for push text, WhatsApp formatter and meta description suggestion.

### C3 Live blog — P1
- Post type `liveblog`. Page shows: LIVE badge, summary box ("ಮುಖ್ಯಾಂಶಗಳು") editors can pin, reverse-chronological updates (time, text, image, video embed, quote, key-update flag), auto-refresh via Supabase Realtime with "N ಹೊಸ ಅಪ್‌ಡೇಟ್‌ಗಳು" button (no jumping content).
- Editor console: quick composer, pin/unpin, edit/delete update, end live blog.
- SEO: LiveBlogPosting JSON-LD; updates visible in HTML.
- Ads: article_in_content slots after update 3 and 10.

### C4 Image layouts
- Featured media options: single, 2-image split (as reference), 3-image collage, video. Captions and credits required.
- Image credit field on every image; "ಚಿತ್ರ: name" shown.

### C5 Web Stories — P2
- Separate AMP story pages `/stories/[slug]` built from an editor (5–15 slides: image, Kannada text overlay, CTA link to article).
- Stories shelf on home and in trending bar. Structured data per Google Web Stories guidelines. Keep optional; visibility on Google varies.

### C6 Photo stories and Photo of the day — P1
- Gallery post type (already in 01) + "ಇಂದಿನ ಚಿತ್ರ" home block with photographer credit.

### C7 Video playlists and series — P0
- `series` table: title, cover, description, ordered posts. Series page with episode list, "ಮುಂದಿನ ಸಂಚಿಕೆ" autoplay prompt, progress per episode (local).
- Video page shows "ಈ ಸರಣಿಯಲ್ಲಿ" rail.

### C8 Audio / podcasts — P2
- Audio post type using external audio URL or YouTube audio; mini player shared with C1.

### C9 Related content upgrades
- "ಇದನ್ನೂ ಓದಿ" inline link blocks inserted by editors inside the body.
- "ಹಿನ್ನೆಲೆ" (background) timeline block for ongoing stories.
- Embedded post cards (paste an internal URL → card).

## N — Community sections

### N1 Community notices `/notices` (ಸಮುದಾಯ ಪ್ರಕಟಣೆ) — P1
- Types: ಶ್ರದ್ಧಾಂಜಲಿ (obituary), ಅಭಿನಂದನೆ (felicitation), ಆಮಂತ್ರಣ (invitation), ವಾರ್ಷಿಕೋತ್ಸವ, ಸನ್ಮಾನ, ವಿದ್ಯಾರ್ಥಿ ಸಾಧನೆ.
- Submitted by readers (form + photo URL/upload ≤ 1 MB) → moderation → published. Optional paid notice (manual payment note in v1).
- Obituary pages: no ads (hide_ads), respectful layout, condolence messages (moderated).

### N2 Opportunities `/opportunities` (ಅವಕಾಶಗಳು) — P2
- Jobs, scholarships, competitions, admissions. Fields: title, organisation, place, last date, link/contact, category. Expired items auto-hide. Reader submissions moderated.

### N3 Basadi directory `/basadis` (ಬಸದಿಗಳು) — P1
- Temple/basadi listings: name, place, district, tirthankara/deity, history summary, timings, contact, map (link to Google Maps; optional embedded map with free tiles), photos, related news and events.
- Filters by district; "ನನ್ನ ಹತ್ತಿರ" (near me) using geolocation.
- Place pages show basadis in that place.

## E — Engagement

### E1 Follow and My feed — P1
- Follow categories, tags, topics, places, authors, series. `/account/feed` shows latest from follows; home "ನಿಮಗಾಗಿ" row uses it.
- Logged-out: follows stored locally, prompt to log in to sync.

### E2 Reading history — P1
- Logged-in: store last 200 viewed posts (`reading_history`); "ಮುಂದುವರಿಸಿ" row; clear history button.

### E3 Polls and quizzes — P1
- Poll block embeddable in articles and home: single/multiple choice, results after vote, one vote per device/user, end date.
- Quiz: questions with answers and explanations; score screen with share card. Good for Jain history/culture quizzes.

### E4 Reactions — P1
- Simple reactions under articles (🙏 ನಮನ, 👍 ಉಪಯುಕ್ತ, 😢 ದುಃಖ) — counts only, one per device. Hidden on obituaries except 🙏.

### E5 Newsletter — P1
- Signup box (email) with double opt-in; daily or weekly digest built automatically from top stories + upcoming events + parva days; editor can add a note. Sent via an email provider (Resend/SES/Brevo — choose in Phase 0). Unsubscribe link, list management in admin.

### E6 Messaging channels — P0
- Header button + sticky share: WhatsApp channel link, Telegram channel link, YouTube subscribe.
- "WhatsApp ನಲ್ಲಿ ಹಂಚಿಕೊಳ್ಳಿ" formatted text: bold title, 2-line summary, link.
- Admin "WhatsApp formatter": generates a ready-to-paste daily bulletin from selected stories.

### E7 Push upgrades — P1
- Rich notifications (image, actions "ಓದಿ", "ನಂತರ"), quiet hours (22:00–06:00 except breaking), frequency cap per user per day, click tracking.

### E8 Comments — P2 (flag)
- Keep from 01 F-63; add profanity filter (Kannada + English word list), report button, shadow-ban, slow mode.

## L — Language

### L1 Interface language toggle — P2
- ಕನ್ನಡ / English switch for UI strings only (`strings.en.ts`). Articles show English version only if `title_en`/`body_en` exist; otherwise Kannada with English UI.
- hreflang only for posts that have both versions.

## Q — Trust and accessibility

### Q1 Trust pages and labels — P0
- Pages: ಸಂಪಾದಕೀಯ ನೀತಿ (editorial policy), ತಿದ್ದುಪಡಿ ನೀತಿ (corrections), ಸತ್ಯಶೋಧನೆ ನೀತಿ (fact-check policy), ಮಾಲೀಕತ್ವ ಮತ್ತು ಹಣಕಾಸು (ownership/funding), ಸಂಪರ್ಕ ತಂಡ.
- Article labels: ವರದಿ (report), ಅಭಿಪ್ರಾಯ (opinion), ವಿಶ್ಲೇಷಣೆ (analysis), ಪ್ರಾಯೋಜಿತ (sponsored), ಸತ್ಯಶೋಧನೆ (fact-check with verdict badge).
- Corrections: "ತಿದ್ದುಪಡಿ: date — what changed" box at article end; `/corrections` log page.
- "Updated" timestamp logic: only for meaningful edits (editor tick box).

### Q2 Authors — P0
- Author page with photo, role, bio, areas, social links, articles. Byline links to it. Person JSON-LD.

### Q3 Accessibility toolbar — P0
- In article tools: text size (3 steps), line spacing, high-contrast mode, dyslexia-friendly spacing; remembered locally.
