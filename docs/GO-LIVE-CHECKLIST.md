- [ ] Real categories, WordPress export, demo exclusion list and video CSV reconciled.
- [ ] Database migrations applied to local dev with approval; RLS tests and advisors pass.
- [ ] Schema-derived TypeScript types generated and integrated.
- [ ] Complete production search beyond the current 200-row preview query.
- [ ] Full CMS, scheduled publication, imports and notification workflows tested.
- [ ] Google/phone login, bookmarks, interests, reminders and logout tested against configured providers.
- [ ] Turnstile, per-IP limits, push subscription ownership and server secrets verified.
- [ ] Push sending and reminder automation implemented with retry/idempotency safeguards.
- [ ] All demo records removed from publication through reviewed scoped operations.
- [ ] Legacy URLs, canonical links, sitemaps, article/video/event metadata and sharing verified.
- [ ] Privacy/terms/contact details approved for the operating organization.
- [ ] Final Vitest, Playwright, Lighthouse, accessibility and real-device checks pass.
- [ ] HTTPS, CDN cache rules, monitoring, backups and rollback tested.
- [ ] Owner approves production migrations and deployment as separate actions.
